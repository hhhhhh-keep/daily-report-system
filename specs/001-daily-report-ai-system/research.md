# 调研决策

## Web 边界

**决策**：一个 `daily-web` Vue 3 应用承载 `/report`、`/my-report` 和 `/admin/*`。
**理由**：一个构建/镜像适合固定内部日报链接和单一管理员。

## 自动化

**决策**：Quartz 在 Spring Boot 内运行，持久化运行结果并控制重试。
**理由**：需要内部调度、报告和邮件；n8n 与队列均被排除。

## 混合分析

**决策**：程序规则计算数量、日期、完整性和阈值；LLM 语义分析综合文本、风险、协同和建议。
**理由**：确定性结果保持可测试；AI 不能改变日报或执行决策。

## 分析维度术语

规划中的分析结论统一使用中文术语：人员效能、工作饱和度、项目进展、项目风险、资源协同、资源调配建议。程序规则负责任务数、项目数、时段覆盖、异常任务、连续支撑与等待反馈等可计算指标；LLM 语义分析负责任务复杂度、风险归纳、问题关联、资源需求识别和管理总结。

## 访问取舍

**决策**：固定内部日报链接使用所选 Employee/日期；单一管理员使用密码登录。
**理由**：员工填写者身份的严格证明明确不属于第一版范围。
