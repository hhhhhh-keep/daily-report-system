# 日报模板版式规范

- Letter纵向（8.5×11英寸），四边页边距0.83英寸。
- 主标题“行一二部工作日报”，黑体18磅、加粗、居中；不得加“领导版”。
- 一级标题黑体15磅，二级标题黑体13磅；正文仿宋_GB2312 11磅、1.5倍行距、首行缩进约23.75磅。
- 驾驶舱使用深蓝底白字，采用2×4布局，依次展示应填写、17:30已填、22:00已填、请假、未填写、有效事项、完成事项、阻塞事项。
- 驾驶舱以外不使用数据表格；填报、人员效能、项目、风险和建议均使用编号段落，保持与参考项目分析报告一致的公文阅读节奏。
- 填报与出勤必须写明应填写人数、17:30/22:00已填写人数与填写率，并列出未填、全天请假、半天请假、待核验人员姓名；无人时写“无”。
- 人员效能先给出部门整体事项分布，再逐条展示有证据的重点人员观察；每条写明姓名及具体项目/专项、动作、产出、主导/协同或明确问题，不得只罗列事项数量或输出泛化评价。
- 项目连续性部分按五工作日窗口说明项目动态日期、关键动作、产出和参与人员；项目关联性部分说明同项目多人、一人多项目和跨组协同，人员须区分主导与协同。
- 项目连续性不显示`暂无正式项目`、`内部专项`等占位分类，不显示数据质量口径说明；过滤后无内容时只保留简短客观结论。
- 正文不得显示`employee-*`、`project-*`等内部标识，不在人员姓名或项目名称后附加系统括号；项目原名称中“标段二”等具有业务含义的括号可保留。
- 风险评估必须区分明确阻塞、信息中断候选、人员集中和超过阈值无动态项目；内部英文状态码统一映射为中文。
- AI不可用时不得输出空白或“待人工补充”；改用确定性事实生成完整报告，并在文末用一行注释说明未采用AI语义补充。
