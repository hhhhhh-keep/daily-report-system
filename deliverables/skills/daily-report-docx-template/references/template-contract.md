# 日报模板稳定接口

## 输入

- `daily-facts/1.2.0`：确定性指标、实名出勤、人员效能、五工作日项目连续性、项目关联性、风险候选和证据限制。
- `daily-analysis/1.2.0`：可选且已通过证据校验的总体判断、人员效能、连续性、关联性、风险和管理建议。

## 模板权威

`assets/daily-report-template.docx` 是页面尺寸、页边距、Normal、Heading 1 和 Heading 2 样式的唯一权威。渲染期间只清理正文锚点并填入业务内容，不得重新设置页面或全局样式。

## 固定组件

- `DR_TITLE`：黑体18磅标题。
- `DR_META`：仿宋11磅中文报告日期与覆盖周期，不显示时区或内部版本。
- `DR_DASHBOARD`：唯一允许使用的表格，2×4指标卡。
- `DR_ATTENDANCE`、`DR_WORK_SUMMARY`、`DR_PROJECTS`、`DR_RISKS`、`DR_ACTIONS`：渲染为标题和编号段落。
- `DR_WORK_SUMMARY`优先渲染已通过证据校验的`efficiency_insights`；无AI增强时，从事实包的人员、项目连续性、动作和产出生成具体的确定性观察。
- 所有正文渲染统一清除内部人员/项目ID及由系统附加的技术括号；项目原始业务名称中的有效括号不受影响。

## 退化策略

AI结果缺失、含错误占位或校验失败时，只移除AI语义补充；确定性驾驶舱、实名出勤、人员效能、项目连续性、关联性、风险候选和管理建议仍须完整输出。

面向领导的Word不显示`暂无正式项目`、`内部专项`和数据质量口径说明；这些信息仍保留在事实包和校验记录中供审计。
