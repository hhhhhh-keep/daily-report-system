## 业务流程

员工填写日报（支持本机草稿） → 当日读取并修改日报 → 管理员维护人员、项目和字典 → 手动或定时运行分析 → Skill 生成 Word 报告 → 按周期发送邮件 → 在任务记录和驾驶舱中查看结果。

项目停用后不参与后续分析；历史日报和历史分析结果仍保留，便于追溯。

## 已完成能力
