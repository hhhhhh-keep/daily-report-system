# 日报模板 Skill 参考报告版式升级设计

## 目标

以《行一二部项目分析报告_2026-07-31.docx》为排版权威，将日报模板 Skill 升级为同源公文视觉系统。保留日报驾驶舱；驾驶舱以下使用附件的标题层级、仿宋正文和连续项目分析段落，避免当前大量表格造成的“系统导出件”观感。

## 已确认版式基线

- 页面：Letter 纵向，8.5 × 11 英寸，四边页边距约 0.83 英寸。
- 主标题：黑体、18 磅、加粗、居中。
- 元数据：仿宋_GB2312、11 磅。
- 一级标题：黑体、15 磅。
- 二级标题：黑体、13 磅。
- 正文：仿宋_GB2312、11 磅，以编号段落表达项目、人员、风险和建议。
- 驾驶舱：作为日报特有组件保留，采用紧凑的 2×4 指标卡，不改变确定性指标口径。

## 结构

1. 行一二部工作日报
2. 报告日期和数据口径
3. 驾驶舱
4. 一、总体概况
5. 二、填报与出勤情况
6. 三、人员效能分析
7. 四、重点项目及协同情况
   - （一）当日正式项目动态
   - （二）日报识别待关联项目
   - （三）超过阈值无动态项目
8. 五、风险问题及协调需求
9. 六、次工作日管理建议

## 技术边界

- `daily-report-template.docx` 提供页面、样式和受控锚点；渲染脚本不得重新覆盖页面尺寸和全局字体。
- 渲染脚本清除锚点后按模板样式生成内容，驾驶舱可使用表格，正文分析不得再以大表格为主。
- 数据仍来自 `daily-facts/1.1.0` 和 `daily-analysis/1.1.0`，不改变规则 Skill 或证据门禁。
- 人员效能与项目动态必须实名；无证据内容不得生成。
- 动态数据长度可以改变分页，因此目标是版式与结构同源，而不是固定页数或逐像素一致。

## 验收

- 自动测试断言 Letter 页面、0.83 英寸页边距、字体字号、章节顺序和除驾驶舱外无数据表格。
- 端到端样例保留 90/88/88/5/2/115/11/12 金标口径。
- DOCX 结构审计通过；若运行环境缺少 LibreOffice，明确记录未执行 PNG 视觉检查。
