# 导入阻塞占位文案清理设计

## 目标

彻底阻断英文占位文案 `Imported blocker needs external coordination` 进入管理报告，同时保留真实中文阻塞说明。

## 数据流

July 导入脚本仅依据原始日报生成任务状态；当任务为阻塞状态但原始日报未提供具体协同要求时，`collaboration_requirement` 保持空值。新增 Flyway 迁移只清空完全等于该占位文案的历史值，不修改状态、项目、进展或真实中文说明。

Word 模板在展示前过滤已知占位文案和无法映射的英文状态码；缺少具体原因的阻塞事项统一描述为“存在阻塞事项，待补充具体原因”。

## 验收

1. 新导入的阻塞任务不含该英文文案。
2. 历史完全匹配该文案的数据被清空，其他协同要求不受影响。
3. 渲染报告不包含该英文文案、英文状态码或空白“阻塞情况：无”。
4. 模板测试、导入脚本语法检查和后端编译通过。
